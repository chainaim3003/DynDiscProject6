### Chainaim Proc

ERPNext customization layer for the **DynDisc V6** seller agent.

This is a standalone Frappe **app** (not a fork of ERPNext) that adds the Custom
Fields, fixtures, and webhooks the agent needs on ERPNext's native `Opportunity`,
`Opportunity Item`, `Quotation`, and `Quotation Item` DocTypes. Keeping the
customizations in a separate app (rather than editing ERPNext source) keeps the
deployment **GPL-safe**.

### Two install paths

1. **REST-only (default for V6.1, no bench required)** — run the seed scripts in
   `erpnextEnh1/seed/`. The Custom Fields are POSTed to a running ERPNext via the
   REST API:
   ```bash
   cd ../../seed
   python 02-install-custom-fields.py --env-file "../../DynDiscProject6/IMPL-V6/.env" --verbose
   ```

2. **Bench app install (optional parity path)** — install as a normal Frappe app;
   `hooks.py` `fixtures` then loads the same 38 Custom Fields on `bench migrate`:
   ```bash
   cd $PATH_TO_YOUR_BENCH
   bench get-app /path/to/erpnextEnh1/apps/chainaim_proc
   bench --site <site> install-app chainaim_proc
   ```

### Custom Fields (38 total)

Defined in `chainaim_proc/custom/*.json`, grounded verbatim in
`DESIGN_6/03-Inquiry-and-Quote-Schemas.md`:

| File | DocType | Fields |
|---|---|---|
| `opportunity.json` | Opportunity | 14 (§1.3) |
| `opportunity_item.json` | Opportunity Item | 6 (§1.4) |
| `quotation.json` | Quotation | 11 (§2.3) |
| `quotation_item.json` | Quotation Item | 7 (§2.4) |

The flat export (`chainaim_proc/fixtures/custom_field.json`) is regenerated by the
seed script's `--emit-fixtures` flag and mirrors the `bench export-fixtures` shape.
